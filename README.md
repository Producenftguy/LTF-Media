# Love Thy Food Media

Website for Love Thy Food Media (a DBA of JIK Services): marketing, OTC and EBT/SNAP renewal paperwork, websites and business email for independent grocers in New York.

- `index.html` is the whole site (static, no build step).
- Hosting: Cloudflare Pages, connected to this repo. Domain: lovethyfoodmedia.com.
- Status: in progress, not live yet. Items in dashed orange boxes still need real numbers or client permission.
